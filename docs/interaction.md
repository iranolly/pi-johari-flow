# 人和 agent 怎么商量一件事

这份文档回答一个问题：**在 pi + pi-web 里，让 agent 停下来问人、人回答、agent 继续，怎样才算好用。**

结论先说：现在能用的只有「弹窗」这一种问答方式，它太窄；pi-web 其实还有几块能放东西的地方，只是没被用起来。下面按「今天能做 / 改 pi-web 一点 / 等 pi 上游」分三层，每层写清能得到什么、代价是什么。

---

## 一、先看清家底

这些都是翻 pi 0.85.1 和 pi-web 0.18.0 的代码确认过的，不是猜的。

| 界面能力 | 能做到什么 | 限制 |
| --- | --- | --- |
| 弹窗（选择 / 确认 / 输入 / 多行） | 屏幕中央弹出，答案直接回到对话；**没答完时侧栏那一条会话会亮橙点，pi-web 还会响一声、发系统通知** | 只能放短字符串：不能放图、不能放折叠的长文 |
| 输入框上方的挂件（`setWidget`） | 一段纯文本，折叠在输入框上方，有新内容时带一个小脉冲点 | 纯文本，只有几行 |
| 底栏状态（`setStatus`） | 常驻一行字 | 一行 |
| 对话气泡（工具结果） | Markdown 和图片；**工具还在执行时就能先显示内容**（边等边看） | 不能跑脚本、不能嵌网页 |
| 文件面板 | `.html` 会真的渲染出来，脚本能跑（我们的决策页按钮在里头能点） | 只能从文件树点进去；聊天里没有"打开这个文件"的入口 |
| 自定义界面（`custom`） | pi-web 已经写好了渲染分支 | pi 0.85.1 还不会发这种消息，属于未来 |

一句话：**橙点、声音、卡片、挂件，今天全都有；"把网页放进侧边"还差 pi-web 一个入口。**

---

## 二、三层方案

### 第一层：对话里商量（今天就能用，已经做了）

- 提问一开始，先往对话里放一张**决策卡**：一句问题、一段背景、每个选项的代价、哪个是推荐。
- `flow_ask`（专问一道题）和带选项/问题的 `flow_page`（意图页、方案页）都会写好页面、开一条只活这道题的本机通道，然后立刻返回。
- agent 把 `[打开完整说明](路径)` 写进**自己的回复**：pi-web 会把回复里的本地链接在它自己的面板里打开（工具结果里的链接只会开新标签），页面里的脚本照常运行。
- 用户点页面上的选项，答案顺着本机通道回到 `flow_wait`，agent 接着做；页面上还能顺手写一句理由，跟着答案一起回来。多题页面要逐题选完再点「提交答案」。输入框上方的挂件从提问开始挂到答案回来。
- 不弹选择框，不抢焦点；用户离开这个会话时，侧栏的橙点和声音（pi-web 自带）会说“这边有一道题”。

得到什么：不用开浏览器、不抢焦点、人不在这一页也会被橙点和声音叫回来、问题不会丢。
代价：卡片是文字，放不下图和多栏对比。

### 第二层：详情页放进 pi-web 自己的面板（要改 pi-web 一小处）

- 让聊天里的本地文件链接**在 pi-web 的文件面板里打开**，而不是新开浏览器标签。
  面板本来就支持渲染 `.html`，决策页原样搬进去即可，按钮照样能点。
- 决策页的按钮本来就会把答案送回对话（0.2 起就实现了），于是形成一条完整的路：
  **卡片在对话 → 详情在侧边面板 → 答案回对话**，全程不离开 pi-web。
- 代价：需要给 pi-web 提一个不大的改动（聊天里的链接拦截 → 打开面板）。
  pi-web 是 MIT 开源，接受外部提交；本地也可以先用开发版跑通。

### 第三层：原生卡片（等 pi 上游）

- pi 目前不会把自定义界面通过 RPC 发出来，pi-web 却已经准备好渲染了。
- 等 pi 支持，决策卡就变成原生组件：可折叠、能带图、按钮直接回传，连页面都不需要。
- 我们这边只是把同样的数据结构换一种发法，前两层的东西不会白做。

---

## 三、一道题的完整流程（第一层，现在）

1. agent 判断这题必须你来定，写一张 5 行以内的卡片。
2. 卡片出现在对话里；输入框上方出现「⏳ 等你拍板」；底栏显示同一件事。
3. 选择框弹出；如果你不在这个会话，侧栏亮橙点、响一声。
4. 你点 B。
5. 卡片变成「已定：B —— 先修链接」，挂件消失，agent 继续。
6. 这道题连同选项、你的选择、时间一起记进会话，事后能查。

---

## 四、边界和兜底

- **人不在**：橙点 + 声音；问题一直挂着，不替你选。
- **关掉弹窗**：卡片和挂件还在，记为未回答，agent 会再问或等你。
- **没有界面**（`-p`、脚本、CI）：卡片照样输出成文字，返回"没答"，不会卡住。
- **页面过期**：在旧页面上点按钮，只会提示「回对话里说 B」，不会把答案记错。

---

## 五、还没定的事

1. 卡片要不要带一张页面缩略图（多花一两秒，换来一眼看到版式）。
2. 第二层是给 pi-web 提改动，还是本地先用开发版。
3. 一次问多道题：现在是一题一弹，多题要不要排成一列卡片。
